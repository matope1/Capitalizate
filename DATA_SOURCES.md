# Fuentes de datos y decisiones geográficas

- **Cobertura:** 193 miembros de las Naciones Unidas y los Estados observadores de Palestina y la Santa Sede/Vaticano. La selección se valida con `unMember` y los códigos `PSE` y `VAT`; debe producir 195 registros.
- **Nombres, capitales, códigos ISO, regiones y coordenadas:** [`world-countries`](https://github.com/mledoze/countries), versión 5.1.0, ODbL 1.0. Las traducciones españolas son la base de los nombres; se normalizan unos pocos nombres habituales y se localizan al español las capitales que suelen escribirse de forma diferente. La tabla generada queda en `data/countries.json` para que la aplicación no dependa de un servicio en línea.
- **Fronteras:** [`world-atlas`](https://github.com/topojson/world-atlas), Natural Earth 1:50m, TopoJSON. Los códigos numéricos ISO se enlazan con el catálogo; se distribuye localmente como `public/countries-50m.json`. Natural Earth representa límites de facto y no pretende resolver disputas territoriales.
- **Punto cartográfico:** la geometría de 50m no incluye Tuvalu. Para no excluirlo, se representa con un marcador en las coordenadas del conjunto de países; no se presenta como frontera poligonal.
- **Continentes:** se usan cinco grupos (América unificada, además de Europa, Asia, África y Oceanía). Rusia se asigna a Asia para conservar los totales de referencia: África 54, América 35, Asia 48, Europa 44 y Oceanía 14. Las barras se calculan desde los 195 registros.
- **Capitales:** se usa como respuesta principal el primer nombre de capital publicado por el conjunto. Los nombres adicionales de capital se conservan como alias aceptados. Para casos con funciones constitucionales/administrativas diferenciadas, el código añade una nota visible y aliases cuando corresponde: Palestina (Jerusalén Este/Ramala), Bolivia, Benín, Costa de Marfil, Sudáfrica, Sri Lanka, Malasia y Tanzania. Para los Países Bajos se aclara que Ámsterdam es la capital constitucional y La Haya sede del Gobierno, sin aceptar La Haya como capital.

Para regenerar el catálogo y el archivo de mapa se ejecuta `npm run data:build`. El script valida cantidad, campos, códigos únicos, distribución continental y excepciones de geometría.
