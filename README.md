# Capitalízate

Juego educativo para aprender las capitales de los 195 países del catálogo mediante un mapa mundial interactivo.

## Ejecutar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Comandos

- `npm run test` — pruebas de catálogo y lógica.
- `npm run lint` — ESLint.
- `npm run build` — compilación de producción.
- `npm run data:build` — regenera el catálogo y el GeoJSON TopoJSON local desde las dependencias fuente.

La procedencia de las fronteras y los datos, así como las decisiones sobre continentes y capitales con varias funciones, se explica en [DATA_SOURCES.md](./DATA_SOURCES.md).
